# Code of conduct

Lily follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good faith, critique code rather than people, and no harassment,
personal attacks or discriminatory language in issues, pull requests, discussions or reviews.

The maintainer ([@pwngoblin](https://github.com/pwngoblin)) may edit, hide or remove contributions and
block participants who don't follow it. To report a problem privately, use the contact details on the
maintainer's GitHub profile.
